# Moviepato (무비파토)

> 보고 싶은 영화 하나만 고르면, 지금 출발해서 **제시간에 도착할 수 있는 모든 영화관과 회차**를 한 화면에 모아 보여 주고, 길찾기와 예매로 이어 주는 서비스예요.

**Demo:** 데모 영상 링크 준비 중

---

## 1. 문제 정의

### 대상 사용자
영화를 보는 모든 사람. 특히 "이 영화를 오늘, 가까운 곳에서 보고 싶다"는 사람이에요.

### 문제 상황
어떤 영화가 보고 싶을 때, 사용자는

1. 먼저 지도에서 주변 영화관을 찾고,
2. 영화관마다 그 영화를 상영하는지 확인하고,
3. 상영 시간이 언제인지, 지금 출발하면 늦지 않는지를 하나씩 따져 봐야 해요.

영화가 아니라 **영화관에서부터 출발하는 탐색 순서** 때문에, 같은 확인을 영화관 수만큼 반복하는 불편이 생겨요.

### 기존 방식과 한계
| 기존 방식 | 한계 |
|---|---|
| CGV·메가박스·롯데시네마 앱 | 근처 영화관을 보여 주지만 **자기 브랜드 영화관만** 보여 줘요. 모든 영화관을 비교하려면 앱을 하나씩 열어야 해요. |
| 네이버 지도에서 "영화관" 검색 | 영화관 위치는 알 수 있지만, **상영 시간표는 다시 따로** 찾아봐야 해요. |
| 네이버 영화 정보 | 영화 정보는 있지만 내 위치·이동 시간과 함께 "지금 가면 볼 수 있는 회차"를 알려 주지는 않아요. |

### 근거
- CGV, 메가박스, 롯데시네마 앱: 각 앱의 극장 찾기는 자사 영화관만 보여 줘요.
- 네이버 지도: 영화관 장소 정보와 상영 시간표가 서로 다른 곳에 있어요.
- 네이버 영화 정보: 영화 중심 정보이고, 출발지·이동수단을 고려한 회차 추천은 없어요.
- 데이터 조사 결과(`docs/data-sources.md`, `BUILD_REPORT.md`): 영화관 3사 모두 상영 시간표·잔여 좌석의 공개 API가 없어요. 그래서 여러 브랜드를 한 번에 비교해 주는 서비스가 나오기 어려웠어요.

### 목표
사용자가 **한 번의 검색으로** 원하는 영화를 볼 수 있는 영화관과 시간대를 찾고, **손쉽게 예매**까지 가게 하는 것이에요.

## 2. 핵심 기능

| 기능 | 해결하는 불편 | 코드 위치 |
|---|---|---|
| 영화 먼저 고르기 | 영화관부터 찾는 순서를 뒤집어, 영화 하나로 탐색을 시작해요 | `frontend/src/screens/MovieSelect.tsx`, `backend/src/routes/movies.ts` |
| 출발 조건 입력 (출발지 검색·현재 위치·이동수단·출발 날짜/시간) | "지금 출발하면 늦지 않을까?"를 사용자가 직접 계산하지 않아도 돼요 | `frontend/src/screens/Departure.tsx`, `backend/src/routes/places.ts`, `backend/src/places/` |
| 브랜드 구분 없는 영화관 추천 | CGV·메가박스·롯데시네마·독립 영화관을 한 목록에서 비교해요 | `backend/src/services/recommend.ts`, `backend/src/data/` |
| 도착 가능 판정 + 빨리 볼 수 있는 순 정렬 | 영화관마다 시간표를 열어 볼 필요 없이, 도착 후 볼 수 있는 가장 빠른 회차를 골라 줘요 | `backend/src/services/availability.ts`, `backend/src/services/ranking.ts` |
| 반경 없이 빠르게 걸러내기 | km 반경으로 자르지 않고 "직선거리 ÷ 최고 속도"로 못 가는 곳만 미리 빼서, 먼 곳의 늦은 회차도 놓치지 않아요 | `backend/src/services/lowerBound.ts` |
| 지도 + 목록 추천 화면 | 위치와 시간을 한눈에 봐요. 출발지와 상위 5곳을 지도에 보여 주고, 카드의 시간 막대(이동 구간은 빨강, 도착 시점 표시)로 언제 도착하는지 보여 줘요 | `frontend/src/screens/Recommend.tsx`, `frontend/src/components/MapView.tsx`, `frontend/src/components/TheaterCard.tsx` |
| 영화관 상세 · 길찾기 · 예매 | 영화관의 회차별 도착 가능 여부를 보고, 카카오맵 길찾기로 바로 넘어가요. 예매 링크가 있는 회차는 공식 예매 페이지로 이어져요 | `frontend/src/components/TheaterDetail.tsx` |
| 실제 데이터 연동 | TMDB 현재 상영작·포스터, 공공데이터 인허가 영화관 목록(좌표 변환 포함)을 써요 | `backend/src/data/tmdb.ts`, `backend/src/data/cinemaCsv.ts`, `backend/src/data/geo5174.ts` |

## 3. 사용 시나리오

1. **영화 선택 (S01)**: 앱을 열고 보고 싶은 영화를 고르거나 검색해요.
2. **출발 조건 (S02)**: 출발지를 검색하거나 현재 위치를 쓰고, 이동수단(자동차·대중교통·도보), 출발 시각(지금 출발 또는 오늘부터 7일 안의 날짜·시간)을 정해요.
3. **추천 보기 (S03)**: 지도와 목록에 그 영화를 상영하는 영화관이 "가장 빨리 볼 수 있는 순"으로 상위 5곳씩 나와요. 카드마다 이동 시간, 도착 시각, 상영 시각이 보여요.
4. **회차 선택 (S04)**: 영화관을 누르면 그날 회차가 나와요. 회차마다 도착 가능 여부와 대기 시간이 보여요.
5. **이동·예매**: "길찾기"로 카카오맵 길찾기를 열어요. "예매하기"는 예매 링크가 있는 회차면 공식 예매 페이지로 가고, 없으면 영화관 공식 사이트에서 예매하라고 알려 줘요.

## 4. 기대 효과

| 항목 | 기존 | Moviepato |
|---|---|---|
| 영화관 비교에 여는 앱·사이트 수 | 지도 1개 + 영화관 앱 3개 이상 | 1개 |
| 원하는 회차를 찾기까지 확인 횟수 | 영화관 수(N곳)만큼 시간표 확인 | 검색 1번 |
| "지금 가면 늦지 않나" 계산 | 사용자가 직접 (출발 시각 + 이동 시간) | 자동 계산, 늦는 회차는 도착 불가로 표시 |
| 회차를 고르기까지 흐름 | 지도 → 브랜드 앱 → 극장 → 시간표 (영화관마다 반복) | 영화 → 출발 조건 → 추천 → 회차 (한 번) |

## 5. 차별점

- **영화 중심 탐색**: 기존 서비스는 "영화관 → 영화" 순서예요. Moviepato는 "영화 → 볼 수 있는 영화관" 순서예요.
- **브랜드 통합**: 자사 영화관만 보여 주는 3사 앱과 달리, 모든 영화관을 한 목록에서 비교해요.
- **시간 기준 추천**: 단순 거리순이 아니라 출발지·이동수단·출발 시각으로 "제시간에 도착할 수 있는 회차"만 골라 줘요. 그래서 가까워도 늦는 곳보다 조금 멀어도 바로 볼 수 있는 곳이 위에 와요.
- **검색 반경 없음**: 반경 안의 결과만 보여 주지 않아요. 도착 불가능한 곳만 계산으로 빼요.
- **정직한 상태 표시**: "도착 불가", "이동 시간 미확인", "상영 없음", "확인 불가"를 구분해 보여 줘요. 일부 조회가 실패해도 나머지 결과는 보여 줘요.

## 6. 설치와 실행

Node.js 22 이상이 필요해요.

```bash
# 0. 레포 받기
git clone https://github.com/candy3157/kirothon-team-010.git
cd kirothon-team-010

# 1. 백엔드 (http://127.0.0.1:3001)
cd backend
npm install
cp .env.example .env        # 키 없이도 샘플 데이터로 동작해요
npm run dev

# 2. 프론트엔드 (새 터미널, http://127.0.0.1:5173)
cd frontend
npm install
cp .env.example .env        # 네이버 지도 키가 없으면 기본 지도 배경으로 보여요
npm run dev
```

브라우저에서 http://127.0.0.1:5173 을 열어요. 프론트의 `/api` 요청은 Vite가 백엔드로 넘겨 줘요.

선택 설정 (`backend/.env`):

| 변수 | 쓰임 |
|---|---|
| `SHOWTIME_PROVIDER=real` + `TMDB_API_KEY` | TMDB 현재 상영작과 인허가 CSV 영화관 사용 (기본은 `sample`) |
| `NAVER_SEARCH_CLIENT_ID` / `NAVER_SEARCH_CLIENT_SECRET` | 출발지 장소 검색 |
| `NCP_MAPS_API_KEY_ID` / `NCP_MAPS_API_KEY` | 주소 → 좌표 변환 |

프론트 `.env`의 `VITE_NAVER_MAP_KEY_ID`를 넣으면 네이버 지도가 보여요. API 키와 `.env` 파일은 커밋하지 않아요.

> 참고: 상영 회차는 공개된 출처가 없어 데모용 값을 써요(`real` 모드도 회차는 데모 값이고 예매 링크가 없어요). 이동 시간도 mock 경로 계산이에요. 실제 예매 링크 연결은 명세(`.kiro/specs/booking-deeplink/`)까지 작성했어요. 자세한 내용은 `docs/data-sources.md`에 있어요.

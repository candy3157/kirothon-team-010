# Moviepato 프론트엔드 디자인 데모

단일 HTML 파일로 만든 화면 흐름 데모입니다. 브라우저에서 `index.html`을 바로 열면 됩니다.

- 화면: 스플래시 → 영화 선택(S01) → 출발 조건(S02) → 지도 추천(S03) → 영화관 상세·회차(S04)
- 데이터: 영화·영화관·상영시간은 모두 가상 데이터(mock)입니다. 실제 API(`docs/openapi.yaml`) 연동 전 디자인 검토용입니다.
- 지도: 실제 지도 SDK가 아닌 가짜 배경 지도입니다.
- 포스터: picsum.photos 임의 이미지를 씁니다(인터넷 필요).

# 위치·이동시간 기반 영화관 추천 서비스 UX 명세서

> **문서 버전:** v1.0  
> **문서 유형:** UX/UI 기능 명세서  
> **대상 플랫폼:** 모바일 웹 우선(반응형 웹)  
> **핵심 가치:** 보고 싶은 영화를 선택하면, 현재 위치와 이동수단·출발 시각을 고려해 **실제로 도착 가능한 상영회차**가 있는 영화관을 지도에서 추천한다.

## 1. 서비스 개요

### 1.1 서비스 목표

사용자가 영화관마다 상영시간표를 개별 검색하고, 지도 앱에서 이동시간을 확인하는 번거로움을 줄인다. 영화 선택부터 영화관 추천, 상영회차 선택, 예매 및 길찾기까지 하나의 흐름으로 연결한다.

### 1.2 핵심 사용자 질문

- 지금 출발하면 어디에서 이 영화를 가장 빨리 볼 수 있는가?
- 실제 이동시간을 고려했을 때 상영 시작 전에 도착할 수 있는가?
- 해당 영화관에서 어떤 회차를 선택할 수 있는가?
- 선택한 영화관으로 어떻게 가고 어디서 예매하는가?

### 1.3 UX 설계 원칙

1. **최소 입력:** 영화 선택 후 현재 위치·출발 시각을 기본값으로 제안한다.
2. **도착 가능성 우선:** 단순 거리순이 아니라 이동시간과 상영시간을 함께 판단한다.
3. **추천 근거 공개:** 이동시간·예상 도착·상영 시작·여유 시간을 함께 표시한다.
4. **지도 중심 탐색:** 지도 마커와 하단 결과 목록을 양방향으로 연동한다.
5. **맥락 유지:** 위치·이동수단·정렬 기준을 바꿔도 선택한 영화를 유지한다.
6. **정보 신뢰성:** 데이터 미확인·조회 실패를 ‘상영 없음’으로 취급하지 않는다.

## 2. 전체 사용자 여정

### 2.1 핵심 UX 흐름

1. **영화 선택** → 검색 또는 현재 상영작 목록에서 원하는 영화 선택
2. **위치 확인 · 이동수단 선택** → 출발지, 교통수단, 출발 시각 확인
3. **지도 기반 최적 영화관 추천** → 도착 가능한 영화관을 지도·추천순 목록으로 탐색
4. **상영시간 선택 · 예매 · 길찾기** → 회차 선택 후 영화관 공식 예매 페이지 또는 지도 앱으로 이동

### 2.2 화면 전환 구조

| 화면 ID | 화면명 | 진입 조건 | 주요 이동 경로 |
|---|---|---|---|
| `S01` | 영화 선택 | 최초 진입 / 영화 변경 | `S02` |
| `S02` | 출발 조건 설정 | 영화 선택 완료 | `S03`, `S01` |
| `S03` | 영화관 추천 지도 | 추천 조회 시작 | `S04`(상세 패널), `S02`(조건 변경), `S01`(영화 변경) |
| `S04` | 영화관 상세·상영회차 | 영화관 마커/카드 선택 | 외부 예매/길찾기, `S03` |

> **화면 구조 권장:** `S01`·`S02`는 단계형 선택 화면, `S03`는 전체 지도 화면, `S04`는 지도 위에 올라오는 바텀시트(Bottom Sheet)로 구현한다. 데스크톱에서는 상세 패널을 지도 우측 사이드 패널로 변경한다.

## 3. 화면별 UX 상세 명세

### S01. 영화 선택

**목적:** 사용자가 보고 싶은 영화를 빠르게 선택하도록 한다.

**주요 UI 구성**

- 상단: 서비스 로고/이름 및 서비스 안내 문구
- 검색창: 영화 제목 입력, 검색 결과 표시
- 콘텐츠 영역: 현재 상영작 목록(포스터, 제목, 개봉연도, 러닝타임 등 제공 가능한 정보)
- 선택 상태: 선택한 영화 강조

**사용자 행동 및 시스템 반응**

| 사용자 행동 | 시스템 반응 |
|---|---|
| 검색어 입력 | 영화 제목 기준 결과를 표시한다. |
| 영화 포스터/항목 선택 | 영화 ID를 저장하고 `S02`로 이동한다. |
| 검색어 삭제 | 기본 상영작 목록으로 되돌아간다. |
| 검색 결과 없음 | ‘검색 결과가 없습니다’ 및 검색어 수정 안내를 표시한다. |

**예외 및 고려사항**

- 영화 제목이 동일한 경우 개봉연도·포스터를 함께 표시해 구분한다.
- 상영 예정작과 현재 상영작을 구분한다.
- 영화 상세 데이터 조회 실패 시 재시도 UI를 제공한다.

**완료 조건:** `selectedMovieId`가 설정되어야 `S02`로 진행할 수 있다.

### S02. 위치 확인 · 이동수단 선택

**목적:** 추천 계산에 필요한 출발 조건을 짧은 단계에서 확보한다.

**주요 UI 구성**

- 선택한 영화 요약(포스터·제목) 및 영화 변경 동작
- 출발지: ‘현재 위치 사용’ 버튼, 주소/장소 직접 검색
- 이동수단: `대중교통` / `자동차` / `도보` 단일 선택
- 출발 시각: 기본값 `지금 출발`, 선택적으로 날짜·시간 지정
- 부가 설정(접기): 상영 전 도착 여유 시간(기본 10분), 검색 반경
- 하단 고정 CTA: **영화관 추천받기**

**사용자 행동 및 시스템 반응**

| 사용자 행동 | 시스템 반응 |
|---|---|
| ‘현재 위치 사용’ 선택 | 브라우저 위치 권한 요청 후 위도·경도와 확인 가능한 출발지 텍스트를 표시한다. |
| 위치 권한 거부 또는 위치 획득 실패 | 주소/장소 수동 입력을 안내한다. |
| 이동수단 선택 | 선택한 수단을 강조하고 기존 선택을 해제한다. |
| ‘지금 출발’ 사용 | 추천 요청 시점의 현재 시각을 기준으로 한다. |
| 날짜·시간 지정 | 지정 시각을 출발 기준으로 저장한다. |
| ‘영화관 추천받기’ 선택 | 필수 값 검증 후 로딩 상태로 전환하고 `S03`로 이동한다. |

**유효성 검증**

- 영화, 출발 좌표, 이동수단은 필수다.
- 위치 권한 동의는 필수가 아니며 수동 입력으로 대체 가능해야 한다.
- 날짜·시간이 과거라면 수정하도록 안내한다.
- 출발 시각 변경 시 이전 추천 결과를 그대로 확정된 결과처럼 보여주지 않는다.

**완료 조건:** `selectedMovieId`, `origin`, `transportMode`, `departureAt`이 모두 유효하다.

### S03. 지도 기반 최적 영화관 추천

**목적:** 도착 가능한 영화관을 추천순으로 비교하고 선택하게 한다.

**주요 UI 구성**

- 상단 요약: 선택 영화, 출발지, 이동수단, 출발 시간
- 조건 변경 UI: 이동수단·출발지·검색 범위 변경, 영화 변경
- 정렬 선택: `가장 빨리 보기`(기본) / `최단 이동` / `여유 있게 도착`
- 지도: 현재 출발 위치, 추천 영화관 마커
- 바텀시트: 추천 결과 목록(접기/확장 가능)
- 각 영화관 카드: 영화관명·브랜드, 이동시간, 예상 도착 시각, 추천 상영회차 시작 시각, 남는 여유 시간, 추천 이유
- 데이터 갱신 시각과 재조회 버튼

**지도 및 목록 연동**

- 지도 마커에는 순위와 추천 상영 시작 시각을 표시한다.
- 마커 선택 → 해당 영화관 카드를 강조하거나 상세 패널을 연다.
- 카드 선택 → 지도 중심을 해당 영화관으로 옮기고 `S04`를 연다.
- 지도 이동만으로 매번 즉시 재조회하지 않는다. 필요 시 ‘이 지역 재검색’ 버튼을 노출한다.

**추천 결과 상태**

| 상태 | UI 동작 |
|---|---|
| 조회 중 | 지도/목록 스켈레톤 및 진행 상태 표시 |
| 관람 가능 영화관 있음 | 순위별 마커와 카드를 표시 |
| 해당 시간대 관람 가능 회차 없음 | 출발 시간 변경·검색 반경 확대·다음 날짜 탐색 제안 |
| 일부 영화관 데이터 조회 실패 | 성공한 결과는 표시하고 실패한 공급자는 ‘일부 정보 미확인’으로 안내 |
| 경로 계산 실패 | 해당 후보를 ‘이동시간 확인 불가’로 구분하고 관람 가능으로 단정하지 않음 |
| 모든 데이터 조회 실패 | 오류 설명, 재시도 및 조건 변경 제공 |

**목록 정렬 원칙**

- 기본 정렬은 **관람 가능한 회차 중 가장 빠른 상영 시작 시각** 우선이다.
- 상영 시작이 같으면 이동시간이 짧은 영화관을 우선한다.
- 하나의 영화관에 회차가 여러 개라면 각 회차를 평가한 뒤, 영화관별 대표 추천 회차를 하나 선택해 목록에 표시한다.
- 관람 불가능한 회차는 기본 추천에서 제외하고, 상세 화면에서는 비활성 처리할 수 있다.

**완료 조건:** 사용자가 영화관을 하나 선택하면 `S04`를 연다.

### S04. 상영시간 선택 · 예매 · 길찾기

**목적:** 추천 결과를 실제 관람 행동으로 연결한다.

**주요 UI 구성**

- 영화관명·주소·브랜드 및 추천 순위
- 출발지 기준 이동시간·예상 도착 시각
- 선택 영화의 해당 날짜 상영회차 목록
- 회차별 시작 시각, 상영관, 상영 포맷, 잔여 좌석(조회 가능 시)
- 도착 불가능한 회차는 비활성화 및 사유 표시
- 선택 회차 요약: 상영 시작 시각, 예상 도착 시각, 상영 전 여유 시간
- 하단 CTA: **예매하기**, **길찾기**

**사용자 행동 및 시스템 반응**

| 사용자 행동 | 시스템 반응 |
|---|---|
| 영화관 카드/마커 선택 | 해당 영화관의 상영회차 목록 표시 |
| 상영회차 선택 | 선택 상태 강조, 도착 여유 시간 재계산 |
| ‘예매하기’ 선택 | 공식 영화관 예매 페이지로 이동(가능할 경우 해당 회차 딥링크) |
| ‘길찾기’ 선택 | 선택 영화관을 목적지로 지도 앱/웹 길찾기 연결 |
| 닫기/뒤로가기 | 영화와 추천 조건·지도 상태를 유지한 채 `S03`으로 복귀 |

**예매 연결 원칙**

- MVP에서는 결제·좌석 선택을 직접 구현하지 않는다.
- 회차별 공식 딥링크가 확인된 경우 우선 사용한다.
- 딥링크가 없는 경우 공식 극장 예매 페이지로 이동하고 회차 재선택이 필요할 수 있음을 안내한다.
- 상영시간표·잔여 좌석은 변경될 수 있으므로 예매 직전 공식 페이지 정보가 최종 기준임을 명시한다.

## 4. 추천 로직과 UX 판정 기준

### 4.1 입력값

| 항목 | 설명 | 기본값 |
|---|---|---|
| 현재 시각 / 출발 시각 | 사용자가 실제 출발하려는 시각 | 지금 |
| 출발 준비 시간 | 출발 전 준비에 필요한 시간 | 0분(MVP) |
| 이동시간 | 선택 수단의 경로 API 예측값 | 실시간 조회 |
| 입장 소요 시간 | 주차·매표·상영관 이동 등에 필요한 시간 | 5분(가정) |
| 상영 전 여유 시간 | 영화 시작 전 확보할 버퍼 | 10분 |
| 검색 반경 | 우선 후보를 탐색할 범위 | 10km(가정) |

### 4.2 도착 가능 여부

```text
예상 입장 가능 시각 = 출발 시각 + 준비 시간 + 이동시간 + 입장 소요 시간
관람 가능 조건 = 예상 입장 가능 시각 + 상영 전 여유 시간 <= 상영 시작 시각
여유 시간 = 상영 시작 시각 - 예상 입장 가능 시각
```

- 이동시간은 직선거리가 아닌 가능한 한 실제 경로 기준으로 계산한다.
- 경로 API가 대기·교통 상황을 완전히 반영하지 않는 경우 예상값임을 표시한다.
- 관람 가능 판정은 보장이 아닌 **예상**이다. 사용자는 실제 교통·상영 상황을 확인할 수 있어야 한다.

### 4.3 기본 추천 우선순위

1. 선택 영화가 상영되고, 출발 조건으로 **관람 가능한 회차**가 있는 영화관만 후보에 포함한다.
2. 영화관별로 가장 빠른 관람 가능 회차를 대표 회차로 선정한다.
3. 대표 회차의 상영 시작이 가장 빠른 영화관부터 정렬한다.
4. 시작 시각이 같다면 이동시간이 짧은 순으로 정렬한다.
5. 추천 카드에 결과의 이유를 설명한다(예: ‘가장 빠른 관람’, ‘이동 12분’, ‘상영 20분 전 도착’).

> ‘최단 이동’ 선택 시에는 이동시간을 최우선 기준으로 변경한다. ‘여유 있게 도착’ 선택 시에는 충분한 버퍼를 가진 회차를 우선하되, 대기 시간이 과도하게 늘어나지 않도록 정렬 규칙을 별도로 정의한다.

## 6. 상태 관리와 화면 간 데이터 유지

```ts
interface SearchContext {
  selectedMovieId: string | null;
  origin: { lat: number; lng: number; label: string } | null;
  transportMode: "transit" | "driving" | "walking";
  departureAt: string | "now";
  arrivalBufferMinutes: number;
  radiusKm: number;
  sortMode: "earliest" | "shortest_travel" | "relaxed";
  selectedTheaterId: string | null;
  selectedShowtimeId: string | null;
}
```

- `S02`에서 조건을 변경하면 `S03` 추천 결과를 새로 계산한다.
- `S03`에서 정렬 기준만 바꾼 경우, 필요한 데이터가 있으면 재조회 없이 정렬만 수행한다.
- `S04` 닫기 또는 뒤로가기 시 이전 지도 중심·스크롤 위치·검색 조건을 유지한다.
- `departureAt = "now"`는 검색 요청을 할 때 실제 현재 시각으로 평가한다.

## 7. 예외 상황 및 피드백 정책

| 상황 | 안내 메시지 / 처리 |
|---|---|
| 위치 권한 거부 | ‘위치를 사용할 수 없습니다. 출발지를 직접 선택해 주세요.’ |
| 주변 영화관 없음 | ‘설정한 반경에 영화관이 없습니다.’ + 반경 확대 |
| 선택한 영화 상영 없음 | ‘선택한 지역·날짜에서 상영 정보를 찾지 못했습니다.’ |
| 도착 가능한 회차 없음 | ‘지금 출발하면 관람 가능한 회차가 없습니다.’ + 늦은 회차/다음 날짜 제안 |
| 상영시간표 오래됨 | 마지막 갱신 시각 표시 + 다시 조회 |
| 경로 API 오류 | ‘이동시간을 확인하지 못했습니다.’ + 재시도 |
| 좌석 데이터 없음 | ‘잔여 좌석 정보 미확인’ 표시, 0석으로 간주하지 않음 |
| 외부 예매 페이지 이동 | 공식 예매 페이지 이동 안내; 회차 재선택 가능성 표시 |

## 8. 접근성 및 반응형 정책

- 모바일: 지도 전체 화면 + 결과 바텀시트, 하단 주요 CTA를 엄지손가락 도달 범위에 배치한다.
- 데스크톱: 지도 + 우측 결과/상세 사이드 패널 구성.
- 마커의 순위·상태를 색상에만 의존하지 않고 숫자/문구로도 전달한다.
- 키보드 조작과 스크린 리더를 고려해 선택 상태·버튼 이름·로딩 및 오류 메시지를 제공한다.
- 지도 외에도 동일한 정보의 목록 탐색을 항상 지원한다.

## 9. MVP 범위

### 필수(P0)

- 영화 검색·선택
- 위치 확인 또는 수동 출발지 지정
- 이동수단 선택 및 ‘지금 출발’ 기준 계산
- 영화관별 상영회차 통합 조회(연동 가능한 공급자부터)
- 실제 경로 기반 이동시간 계산
- 관람 가능 여부와 기본 순위 계산
- 지도 마커 + 결과 리스트 + 상세 패널
- 회차 선택 및 공식 예매/길찾기 연결
- 로딩·빈 결과·API 오류 처리

### 선택(P1)

- 검색 반경·출발 시간·여유 시간 설정
- 최단 이동/여유 도착 정렬
- 잔여 좌석 정보
- 영화 포맷(IMAX/4DX 등) 필터

### 후순위(P2)

- 즐겨찾기 및 사용자 프로필
- 교통 변동 감지 및 출발 알림
- 영화관 공식 예매 연동 고도화
- 개인화 추천

## 10. 주요 성공 기준(수용 테스트)

- [ ] 영화 선택 후 화면 전환 시 선택 영화 정보가 유지된다.
- [ ] 위치 권한을 거부해도 수동 출발지 입력으로 추천을 진행할 수 있다.
- [ ] 이동수단 변경 시 이동시간과 추천 순위가 갱신된다.
- [ ] 도착이 불가능한 회차가 ‘관람 가능’으로 표시되지 않는다.
- [ ] 지도 마커 선택과 추천 카드 선택이 같은 영화관 상세 화면을 연다.
- [ ] 영화관 상세에는 가능한 상영회차와 예상 도착 시각이 표시된다.
- [ ] 예매하기는 영화관 공식 사이트로, 길찾기는 해당 영화관 목적지로 연결된다.
- [ ] 데이터 미확인·조회 실패·상영 없음 상태가 서로 구분된다.
- [ ] 상세 화면을 닫아도 검색 조건과 지도 탐색 상태가 유지된다.

## 11. 개발 및 운영 시 주의사항

- 영화관의 내부 웹 요청에 의존할 경우 인터페이스 변경·접근 정책·이용약관 등을 확인해야 한다.
- 상영회차·좌석·교통정보는 조회 시점 기준의 정보이므로 마지막 갱신 시각을 명시한다.
- 지도 및 길찾기 API의 과금·호출 한도를 확인하고 캐시·사전 필터링을 적용한다.
- 위치 정보는 사용자 동의 아래 필요한 범위에서 사용하며, MVP에서는 불필요한 장기 저장을 피한다.
- 외부 예매 사이트의 결제·좌석 확정 여부를 자체 서비스에서 보장하지 않는다.
